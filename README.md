## Tecnologías Utilizadas

- **React** con **TypeScript**
- **Vite** como herramienta de construcción

## Requisitos del Sistema

- **Node.js v22.11.0** (requerido)
- **npm** (incluido con Node.js)

⚠️ **Importante**: Sin Node.js instalado, el prototipo no puede ejecutarse.

## Instalación y Configuración

```bash
# Navegar al directorio del código fuente
cd code

# Instalar dependencias del proyecto
npm install

# Instalar axios para conexión con backend
npm install axios

# (Opcional) Auditoría y corrección de vulnerabilidades
npm audit fix --force

# Ejecutar el servidor de desarrollo
npm run dev
```
